Command details

Decoded fields are grouped by what they mean. Reserved and unused fields stay out of the way.

Admin command

Get Log Page — SMART / Health Information

Reads the controller’s SMART / Health Information log page.

Command fields
Log page
SMART / Health Information
LID 0x02 selects the SMART / Health Information log.
Retain events
No
RAE is clear, so the controller may clear the associated asynchronous event.
Log page offset
0 bytes
The transfer starts at the beginning of the log page.
Transfer length
4 bytes
NUMD is zero, representing one dword (NUMD + 1).
Namespace
Global
NSID 0x00000000 addresses a global log page.
